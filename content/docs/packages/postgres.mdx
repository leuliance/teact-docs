`@teactjs/postgres` stores Teact state in a single Postgres table: a `PostgresDriver`
(`AsyncStorageDriver`) for `storagePlugin` and `useStorage`, `postgresSessionStore` for durable
sessions, and `postgresPlugin` + `usePostgres` to run SQL from components. It works with any
Postgres — Supabase, Neon, Vercel Postgres, RDS, self-hosted and PGlite. If you use Drizzle or Prisma,
pass the underlying `pg` pool.

```npm
npm i @teactjs/postgres @teactjs/storage pg
```

Install **one** client: `pg` (node-postgres), `postgres` (postgres.js), `@neondatabase/serverless`
(Neon) or `@electric-sql/pglite`. All are optional peers (`pg >=8`, `postgres >=3`,
`@neondatabase/serverless >=0.9`, `@electric-sql/pglite >=0.2`); the driver talks to them through
small structural interfaces and never imports them. Other peers: `@teactjs/core`,
`@teactjs/storage`, `@teactjs/plugin-sdk`, `react`.

With the CLI: `teact add postgres --client neon` (`pg` | `postgres` | `neon` | `pglite`; aliases
`pg`, `postgresql`, `neon`, `supabase`).

**When to use**

- You already run Postgres and want bot state and sessions next to your app data.
- You want SQL access (`usePostgres().query`) for leaderboards, reports and joins.
- On the edge, with Neon's HTTP driver.

## Quick example

<Tabs items={['pg', 'postgres.js', 'Neon (HTTP)', 'PGlite']}>
<Tab value="pg">

```ts title="src/db.ts"
import { Pool } from "pg";
import { storagePlugin } from "@teactjs/storage";
import { PostgresDriver, postgresPlugin, postgresSessionStore } from "@teactjs/postgres";

const pool = new Pool({ connectionString: process.env.DATABASE_URL });
export const pg = new PostgresDriver({ client: pool, closeClient: true });

export const plugins = [storagePlugin({ driver: pg }), postgresPlugin({ driver: pg })];
export const sessionStore = postgresSessionStore(pg, { ttl: 30 * 24 * 3600_000 });
```

</Tab>

import { createBot } from "@teactjs/core";
import { TelegramAdapter } from "@teactjs/telegram";
import { plugins, sessionStore } from "./db";

## Exports

| Export | Kind | Signature | Description |
| ------ | ---- | --------- | ----------- |
| `PostgresDriver` | class | `new PostgresDriver(opts: PostgresDriverOptions)` | `AsyncStorageDriver` over one table. |
| `postgresSessionStore` | function | `(source: PostgresDriver \| PostgresDriverOptions, opts?: CreateSessionStoreOptions) => SessionStore` | Durable sessions. |
| `postgresPlugin` | function | `(opts: PostgresPluginOptions) => TeactPlugin` | Registers a driver as the `'postgres'` service (plugin name `teact-postgres`). |
| `usePostgres` | hook | `() => PostgresDriver` | The registered driver; `query()` runs raw SQL. |
| `POSTGRES_SERVICE` | const | `'postgres'` | Service key. |
| `fromPg` | function | `(client: PgLikeClient) => QueryFn` | pg `Pool`/`Client`, Neon `Pool`, `@vercel/postgres`, any pg-compatible pool. |
| `fromPostgresJs` | function | `(sql: PostgresJsLikeClient) => QueryFn` | postgres.js (uses `sql.unsafe(text, values)`). |
| `fromNeon` | function | `(sql: NeonLikeClient) => QueryFn` | Neon HTTP `neon()` (`sql.query()` or the older `sql(text, values)`). |
| `fromPglite` | function | `(db: PgliteLikeClient) => QueryFn` | PGlite. |
| `toQueryFn` | function | `(client: PostgresClient) => QueryFn` | Auto-detect and adapt a client. |
| `closeClient` | function | `(client: PostgresClient) => Promise<void>` | Call `end()` (pg, postgres.js) or `close()` (PGlite). |
| `createTableSql` | function | `(table = 'teact_storage', schema?: string) => string` | The DDL as one string. |
| `createTableStatements` | function | `(table = 'teact_storage', schema?: string) => string[]` | The DDL statements. |
| `quotePgIdent` | function | `(name: string) => string` | Validate and double-quote an identifier. |

Types: `PostgresDriverOptions`, `PostgresPluginOptions`, `QueryFn`
(`(text, values?) => Promise<Row[]>`), `Row`, `PostgresClient`, `PgLikeClient`, `PgliteLikeClient`,
`PostgresJsLikeClient`, `NeonLikeClient`.

## PostgresDriver

<TypeTable
  type={{
    client: { type: 'PostgresClient', description: 'pg Pool/Client, postgres.js sql, Neon neon() or Pool, PGlite, or a QueryFn. Auto-detected.', required: true },
    table: { type: 'string', description: 'Table name; validated and quoted.', default: "'teact_storage'" },
    schema: { type: 'string', description: 'Schema, e.g. "bot" → "bot"."teact_storage". Must exist.', default: 'search_path' },
    autoMigrate: { type: 'boolean', description: 'Create the table and index lazily on first use (CREATE … IF NOT EXISTS).', default: 'true' },
    closeClient: { type: 'boolean', description: 'End the client in close(), which storagePlugin calls on stop.', default: 'false' },
  }}
/>

Client detection (`toQueryFn`): a function with `.unsafe` is postgres.js; a function with `.query`
is Neon HTTP; an object with `.query` is pg / PGlite / Neon `Pool`; any other function is a
`QueryFn`. Anything else throws `Unsupported client`.

### Methods

| Method | Description |
| ------ | ----------- |
| `get<T>(key)` | Read a live value (expiry checked in SQL against `now()`). |
| `set(key, value, { ttl? })` | Single-statement upsert; `ttl` in ms sets `expires_at`. `undefined` deletes. |
| `incr(key, by = 1, { ttl? })` | Atomic counter in one `UPSERT … RETURNING`, exact `numeric` arithmetic. Missing or expired rows count as 0 and get the `ttl`; a live row keeps its expiry. Rejects when the stored value is not a JSON number. |
| `delete(key)`, `has(key)` | Remove / check a live key. |
| `keys(prefix?)` | Live keys, sorted. |
| `entries(prefix)` | Live `[key, value]` pairs in one query. |
| `clear(prefix?)` | Delete under `prefix`, or the whole table. |
| `purgeExpired()` | Delete expired rows; resolves the number removed. |
| `query<R>(text, values?)` | Raw parameterised SQL (`$1`, `$2`, …) on the same client. |
| `migrate()` | Create the table now (otherwise lazy); retried if it failed. |
| `close()` | Ends the client only with `closeClient: true`. |

Properties: `client` (as passed in) and `tableRef` (the quoted, qualified table name).

Prefixes are matched literally: `%`, `_` and `\` are escaped (`LIKE $1 ESCAPE '\'`).

### Schema and migrations

```sql title="migrations/001_teact_storage.sql"
CREATE TABLE IF NOT EXISTS "teact_storage" (key TEXT COLLATE "C" PRIMARY KEY, value JSON NOT NULL, expires_at TIMESTAMPTZ);
CREATE INDEX IF NOT EXISTS "teact_storage_expires_at_idx" ON "teact_storage" (expires_at) WHERE expires_at IS NOT NULL;
```

`createTableSql(table, schema?)` returns exactly this. If you run migrations yourself (Drizzle Kit,
Prisma Migrate, Supabase migrations), add it there and pass `autoMigrate: false`.

- `COLLATE "C"` lets prefix `LIKE` queries use the primary-key b-tree.
- `JSON` (not `JSONB`) keeps object key order and accepts `\u0000` in strings. Tables created with
  `JSONB` by older versions keep working; there is nothing to migrate.
- Two processes racing `CREATE TABLE IF NOT EXISTS` on a fresh database may see SQLSTATE `23505`
  or `42P07`; the driver treats both as success.

```ts
import { createTableSql } from "@teactjs/postgres";
console.log(createTableSql("bot_state", "bot")); // "bot"."bot_state" + "bot_state_expires_at_idx"
```

<Callout type="info" title="Expired rows">
Expired rows are hidden from every read, but stay on disk until deleted. If you use `ttl` heavily,
run `pg.purgeExpired()` from a cron job.
</Callout>

## postgresSessionStore

```ts
postgresSessionStore(pg, { prefix: "session:", ttl: 30 * 24 * 3600_000 });
postgresSessionStore({ client: pool, table: "sessions" }); // its own driver and table
```

The first argument is a `PostgresDriver` or driver options; the second is `CreateSessionStoreOptions`
(`prefix` default `'session:'`, `ttl` in ms). Each session write is awaited before the update
finishes, so it is safe on serverless.

## postgresPlugin and usePostgres

  type={{

    client: { type: 'PostgresClient', description: 'Or build a new driver from these options (client required when there is no driver).' },
    table: { type: 'string', description: 'Driver option.' },

Without `client` or `driver` it throws `postgresPlugin needs { client } or { driver }`.

```tsx title="src/screens/Leaderboard.tsx"
import { useQuery } from "@teactjs/core";
import { Message } from "@teactjs/ui";
import { usePostgres } from "@teactjs/postgres";

export function Leaderboard() {
  const pg = usePostgres();
  const { data, isLoading } = useQuery({
    key: "top-10",
    fn: () =>
      pg.query<{ name: string; points: number }>(
        "SELECT name, points FROM scores ORDER BY points DESC LIMIT $1",
        [10],
      ),
  });
  if (isLoading) return <Message text="Loading…" />;
  return <Message text={data!.map((r, i) => `${i + 1}. ${r.name} — ${r.points}`).join("\n")} />;
}
```

## Edge and serverless

- Neon's HTTP driver (`neon()`) works on Cloudflare Workers, Vercel Edge and other fetch-only
  runtimes because each query is a single HTTPS request.
- `pg` and `postgres.js` need TCP sockets (Node, Bun). On serverless functions, use your provider's
  pooler (Supabase's transaction pooler, Neon's pooled connection string).
- The table migration runs once per process (or isolate), on the first query.

<Callout type="warn" title="Shared pools">
Leave `closeClient` / `closeOnStop` off when the pool is shared with the rest of your app — the
driver would end it on `bot.stop()`.
</Callout>

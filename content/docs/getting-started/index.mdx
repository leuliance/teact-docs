## The short version

```bash
bun create teact my-bot
cd my-bot
# add TELEGRAM_BOT_TOKEN=... to .env
bun dev
```

Then send `/start` to your bot in Telegram.

<Callout type="info">
  Import **components** from `@teactjs/ui` and **everything else** (`createBot`, hooks, the router,
  `defineConfig`) from `@teactjs/core`. The old `@teactjs/react`, `@teactjs/runtime`, and
  `@teactjs/renderer` packages were folded into `@teactjs/core`.
</Callout>

When you are comfortable here, open **[Router](/docs/guides/router)** and **[Commands](/docs/guides/commands)** to structure real bots.
